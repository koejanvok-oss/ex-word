One word, the word an ex would use to describe you: **Avoidant**. The
clinical word every ex reaches for — emotionally unavailable, gone the
moment things get real. It is funny because it is painfully honest, and
the person who hears it knows exactly why it fits.

## Run

```sh
python3 main.py
```

This writes exactly `Avoidant` (8 characters, no trailing newline) to
`/output/entry.txt`.
